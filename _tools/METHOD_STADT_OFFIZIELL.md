# STRIKTER MASSSTAB: NUR OFFIZIELLE STADT-/GEMEINDE-DOMAIN

Ziel: Seiten auf der OFFIZIELLEN Domain einer Stadt/Gemeinde, auf denen Sponsoren/
Förderer/Partner (Firmen) veröffentlicht werden — idealerweise dofollow verlinkt
(Vorbild: https://www.nordhorn.de/portal/seiten/sponsor-innen-900000253-26710.html).

## ZÄHLT NUR (offizielle Domain):
- Die eigene Domain der Kommune: z.B. nordhorn.de, dortmund.de, ravensburg.de,
  hamm.de, langenfeld.de, neuwied.de, offenbach.de — sowie deren SUBDOMAINS
  (z.B. kultursommer.goettingen.de, visit.ludwigsburg.de, theater.ingolstadt.de,
  altstadtfest.saarbruecken.de). Subdomain ist OK, solange die Registrable-Domain
  die offizielle Stadtdomain ist.

## STRIKT AUSGESCHLOSSEN (egal wie viele Firmen dort verlinkt sind!):
- Stadtmarketing-/Citymanagement-/City-Marketing-/Werbegemeinschafts-VEREINE auf
  eigener Domain (stadtmarketing-xy.de, citymanagement-xy.de, cm-xy.de, xy-aktiv.de,
  au-bb.de, gmerleben.de, ulmercity.de, innenstadt-xy.de, pro-xy.de, xy-city.de ...)
- Tourismus-/Marketing-GmbHs auf eigener Domain (xy-tourismus.de, visit-xy.de,
  xy.travel, xy-info.de, xy-erleben.de, lueneburg.info, region-xy.de, destination-xy.de)
- Event-/Festival-Domains (sandkerwa.de, kieler-woche.de, bergkirchweih.info,
  heinerfest.de, laternenfest.de, canaletto-fest.de, maschseefest.de, *2025.de ...)
- JEDE sonstige separate Domain, auch wenn die Stadt Gesellschafter ist.
Wenn die Firmenliste NUR auf so einer Domain liegt -> Stadt = KEINE FIRMEN (offiziell).

## VORGEHEN je Stadt:
1. Offizielle Domain bestimmen (meist stadtname.de / stadt-stadtname.de).
2. Gezielt suchen: WebSearch "site:<offizielle-domain> sponsoren OR förderer OR
   sponsoring OR partner OR unterstützer", zusätzlich Stadtfest-/Weihnachtsmarkt-/
   Ehrenamtspreis-/Jubiläums-Seiten AUF der offiziellen Domain prüfen.
3. dofollow-Linkanalyse der gefundenen offiziellen Seite.

## Status:
- FIRMEN-LINKS: offizielle Domain-Seite mit >=6 dofollow-Firmenlinks
- FIRMEN-LOGOS: offizielle Domain-Seite mit >=4 Firmen-Logos/Namen, unverlinkt/nofollow
- PARTNERBEREICH: offizielle Domain-Seite mit 1-5 Firmen genannt/verlinkt
- KEINE FIRMEN: keine Firmen-Sponsorenseite auf der offiziellen Domain (Portale zählen NICHT)

## Output je Stadt (JSON, Schlüssel wie gehabt). listungsseite MUSS auf der offiziellen
Domain liegen. In bewertung: offizielle Domain bestätigen + Firmenbeispiele + dofollow-Zahl.
Bei Treffern Hunter-verifizierten Ansprechpartner (Stadt-Pressestelle/Stadtmarketing-Amt/
Eventbüro) angeben.
